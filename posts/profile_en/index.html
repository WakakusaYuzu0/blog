Development Experience

I have been programming since junior high school and have experience with Python, Go, C, C++, Java, OCaml, Verilog, and other languages.

During my master’s program, I worked on several machine learning and data science internships, including weather prediction from 3D radar data, recommendation model improvement for a dating app, large-scale data analysis with BigQuery, and inventory optimization.

During my undergraduate research, I joined Kashima Laboratory, where I worked on data analysis and applied machine learning. I also gained practical experience through internships and part-time roles involving anomaly detection on quantized neural networks, OCR model improvement, Japanese character dataset construction, and machine learning for compound exploration in drug discovery.

I have also worked on systems programming and backend development. As an undergraduate, I implemented a CPU with a five-stage pipeline and branch prediction on an FPGA using Verilog. I also implemented interpreters and type inference programs using OCaml, and developed backend API servers in Go during an internship.

In my second year of university, I developed a Python program for Kyoto University students that automatically collected assignment lists by scraping a course website and supported scheduled assignment submissions.

I have participated in competitive programming since my first year of university. On AtCoder, I reached a rating of 1382, corresponding to the cyan rank.
